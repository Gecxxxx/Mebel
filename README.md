# Приоритет — сайт мебельного ателье

Материалы 6 ноября: мини-каталог проектов с примерами стоимости, видеовизитка на главной и странице About и сертификат с подарками. Окно предложения появляется примерно через 7 секунд видимого просмотра, один раз за посещение вкладки; крестик, Escape и клик по фону закрывают его. Кнопка «Сертификат и подарки» открывает предложение повторно. Форма, играющее видео, меню и другая открытая галерея откладывают автоматический показ. На страницах заявки, конфиденциальности и ошибки окна нет. Заявки на сертификат и подарки различаются по источнику, но сертификат не считается выданным автоматически. `npm run test:promotions` проверяет эти условия и материалы.

Демонстрационная версия: https://gecxxxx.github.io/Mebel/.

Основной домен: https://prioritetmebel48.ru/. Серверная сборка `npm run build:vps` использует этот домен для SEO и открывает содержательные страницы для индексации. Инструкция переноса, обновления VPS и переключения DNS — в `deployment/vps/README.md`.

Яндекс Метрика `114121807` подключена один раз через общий `src/layouts/Base.astro` на всех страницах. Сохранены Вебвизор, карта кликов, отслеживание ссылок, точный показатель отказов и `ecommerce: 'dataLayer'`. Текстовые поля заявки и опроса помечены `ym-disable-keys`; информация об аналитике есть на странице конфиденциальности.

Astro формирует самостоятельный HTML для каждой страницы. React используется для меню, моделей, фильтров, избранного, вариантов исполнения, увеличенных галерей и формы обращения.

## Разделы

- Кухни: самостоятельное направление мебели на заказ.
- Корпусная мебель: шкафы, гардеробные, прихожие, гостиные, детские, спальни и встроенные решения.
- Столы и стулья: 168 моделей с карточками, исполнениями, поиском, брендами и избранным.
- Наши работы: 25 альбомов с категориями; 23 новых альбома содержат 59 отобранных фотографий ателье. Кадры до установки, изображения проектов и процесс имеют отдельные подписи.
- Компания, шоурум, контакты двух салонов, материалы, порядок заказа, доставка и оплата, гарантийные обращения и FAQ.

Тёмно-золотая палитра, локальные шрифты Onest/Golos Text, разделённый первый экран и адаптивные макеты сохранены. Декоративный слой и стили альбомов находятся в `src/warmth.css`.

## Запуск и проверка

Требуется Node.js 24 и проверенный lockfile.

```sh
npm ci
npm run dev
```

Сборка для GitHub Pages и обязательные проверки:

```sh
npm run build:pages
npm run test:sites
npm run test:static
npm run test:catalog
npm run test:leads
npm run preview:pages
```

`npm run build` создаёт сборку для корня домена. `build:pages` учитывает `/Mebel/`. Сохраняется упаковка Sites: `dist/client`, `dist/server/index.js`, `dist/.openai/hosting.json`.

## Публикация

Push в `main` запускает workflow **Publish website**: установка зависимостей, сборка, проверки и публикация `dist/client`. Возможен ручной запуск Actions → Publish website → Run workflow.

GitHub Pages используется для согласования демонстрационной версии. Сохраняется `noindex,follow`; индексация включается только при намеренном запуске на основном домене через `PUBLIC_INDEXABLE=true`.

## Данные и фотографии

- `src/data/site.js` — контакты, меню, работы, FAQ, этапы заказа и согласованные тексты.
- `src/data/services.js` — направления мебели.
- `src/data/works.js` — альбомы новых работ, категории и подписи этапов.
- `src/data/work-photo-sources.json` — имена исходных фотографий и реальные размеры WebP-вариантов.
- `scripts/import-client-works.py` — техническая подготовка фотографий через Python/Pillow: ориентация, уменьшение и WebP; без ретуши, дорисовки и увеличения сверх исходного разрешения.
- `src/data/photos.js` и `photo-sources.json` — отдельная фотосъёмка шоурума. Она не выдаётся за работы у заказчиков; бывшая сотрудница с короткой стрижкой исключена.
- `src/data/catalog.json` — исторический архив 168 моделей и вариантов с прежнего сайта `stolyistulya48.ru`.
- `src/data/products.js` — данные моделей для сайта: исторические суммы удалены до передачи в HTML и React. На сайте везде указано «Стоимость уточняйте». Фильтрация и сортировка по старым ценам отключены.
- `src/data/routes.js` — канонические страницы и совместимость старых адресов.

Новые адреса направлений: `/kuhni/`, `/korpusnaya-mebel/`, `/stoly-i-stulya/`. Старые адреса `/catalog/...` и `/mebel-na-zakaz/...` открывают соответствующую новую страницу, сохраняя query/hash. При отключённом JavaScript доступна обычная ссылка. В sitemap включены канонические страницы.

Столы, стулья и подбор обеденных групп остаются отдельными понятиями: подборка группы содержит индивидуальные предметы, а состав и стоимость комплекта согласуются отдельно. Наличие из старой выгрузки не считается актуальным.

## Границы версии

Опрос из пяти вопросов и форма проекта отправляют заявки в отдельный сервис Sites с закрытой D1. Telegram и MAX доставляют новые обращения всем подключённым подписчикам: `/start` → пароль → `/status`; `/stop` отключает подписку. Публичные страницы не содержат токенов или пароля. Описание сервиса, подтверждения сохранения/доставки и поведения очереди: [lead-service/README.md](lead-service/README.md). CMS, CRM и оплата не подключены. Избранное хранит только номера моделей в localStorage браузера; ввод клиента не записывается в статические файлы.

Правки ноября: крупное контурное меню, Telegram/MAX/WhatsApp, Manrope в главном заголовке, компактные карусели со стрелками, фотографические направления корпусной мебели, отдельные About и Contacts с картами. Фасад отретуширован через ImageGen; источник и обработка записаны в `src/data/exterior-photo-provenance.json`. Оригиналы фотографий сохранены. Единые светлые подложки каталога не изменяют мебель на исходных снимках.

Сроки, комплектация, гарантии и условия фиксируются по заказу. Гарантийные права при обнаружении недостатков не смешиваются с ограничениями на возврат качественной мебели по индивидуальному проекту. Логотип временный; лицензии шрифтов и иконок находятся в `public/assets/licenses/`.
