# Приоритет — сайт мебельного ателье

Адаптивный сайт на React и Vite: главная, галереи мебели, контакты двух салонов и подготовка обращения. Выбранная концепция — тёмно-золотое оформление с реальными фотографиями клиента.

## Онлайн-просмотр

Адрес GitHub Pages после успешной публикации: **https://gecxxxx.github.io/Mebel/**.

Изменения в ветке `main` автоматически собираются и публикуются через GitHub Actions. Обычное время обновления — несколько минут. Уже открытый сайт нужно обновить в браузере.

Для повторной публикации без изменения кода: **Actions → Publish website → Run workflow → main**. Результат и журнал сборки находятся в том же разделе.

Настройка репозитория: **Settings → Pages → Source: GitHub Actions**. Доступность Pages для закрытого репозитория зависит от тарифа GitHub; на бесплатном тарифе нужен открытый репозиторий.

## Локальный запуск

Требуется Node.js 24.

```sh
npm ci
npm run dev
```

## Проверка и сборка

```sh
npm run build:pages
npm run test:sites
npm run preview:pages
```

Сборка для GitHub Pages учитывает адрес `/Mebel/`, включая фотографии, иконки и шрифты. Публикуется только `dist/client`. Если название репозитория изменится, обновите `--base` в `build:pages`.

`npm run build` создаёт обычную сборку для корня домена и сохраняет совместимость с исходным шаблоном Sites.

## Что редактировать

- `src/App.jsx` — тексты, проекты, адреса, часы работы и ссылки.
- `src/prototype.css` — оформление и адаптация под размер экрана.
- `public/assets/` — фотографии, временный логотип, шрифты и иконки.
- `.github/workflows/deploy.yml` — автоматическая публикация.

## Границы текущей версии

Форма проверяет данные и готовит сообщение, которое посетитель сам копирует и отправляет в Telegram. Автоматическая отправка, CRM, корзина и онлайн-оплата не подключены. Сайт можно показывать по ссылке; для запуска продаж потребуются соответствующие интеграции и документы.

Текущий логотип временный. Изображение материалов отмечено как иллюстрация и не является фотографией салона. Фотографии проектов предоставлены клиентом. Лицензии шрифтов и иконок находятся в `public/assets/licenses/`.
