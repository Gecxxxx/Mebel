# Приоритет — многостраничный сайт мебельного ателье

Демонстрационная версия: **https://gecxxxx.github.io/Mebel/**.

Astro формирует самостоятельный HTML для каждой страницы. React используется для мобильного меню, каталога, фильтров, избранного, вариантов товаров, галерей и формы обращения. Страницы открываются по прямой ссылке и после обновления браузера без SPA-переадресации.

## Разделы

- Главная в утверждённом тёмно-золотом оформлении.
- Кухни, мебель на заказ, шкафы и гардеробные.
- Каталог: столы, стулья и подбор обеденной группы.
- 168 самостоятельных карточек моделей, перенесённых из прежнего каталога.
- Портфолио и две подробные истории: шкаф под лестницей и экспозиционная кухня ГЕОС Идеал.
- Материалы, порядок заказа, компания, шоурум, контакты двух точек, доставка и оплата, гарантийные обращения и FAQ.
- Подготовка обращения и описание работы с данными в демонстрационной версии.
- Собственная страница 404 и техническая карта сайта.

## Запуск

Требуется Node.js 24.

```sh
npm ci
npm run dev
```

Для проверки именно пути GitHub Pages:

```sh
npm run build:pages
npm run test:sites
npm run test:static
npm run preview:pages
```

`npm run build` создаёт сборку для корня домена. `build:pages` учитывает `/Mebel/`. Сохраняется совместимость с исходным шаблоном Sites: `dist/client`, `dist/server/index.js`, `dist/.openai/hosting.json`.

## Публикация

Push в `main` запускает workflow **Publish website**: установка зависимостей, сборка, проверки страниц и ресурсов, публикация `dist/client`. Для ручного запуска: **Actions → Publish website → Run workflow → main**. Если название репозитория меняется, нужно обновить `--base` в командах Pages.

GitHub Pages используется для согласования демонстрационного макета. Перед запуском коммерческого сайта нужен подходящий рабочий хостинг. Демо содержит `noindex,follow`; включать индексацию следует только после переноса на основной домен и проверки содержания, установив `PUBLIC_INDEXABLE=true` при сборке.

## Где находятся данные

- `src/data/site.js` — контакты, расписание, проекты, FAQ и этапы заказа.
- `src/data/services.js` — страницы направлений.
- `src/data/catalog.json` — товары, параметры, варианты, исходные адреса и ценовые ориентиры.
- `src/data/catalog-provenance.json` — источники и дата переноса каталога.
- `src/data/routes.js` — перечень статических страниц.
- `src/layouts/Base.astro` — общий каркас и метаданные.
- `src/components/` — шаблоны страниц и интерактивные компоненты.
- `src/prototype.css` — исходные визуальные правила выбранной концепции.
- `src/pages.css` — внутренние страницы и адаптация.
- `src/typography.css` — шрифты Onest / Golos Text и компоновка первого экрана без наложения текста на фотографию.
- `public/assets/` — локальные изображения, шрифты и иконки.

Контент отделён от представления для последующего подключения CMS. В текущей версии админка и серверная база не подключены.

## Перенос каталога

Источники: публичный каталог `stolyistulya48.ru` — столы, стулья и подбор обеденных групп. Поля с перепиской или персональными данными не импортировались. Карточка с названием `Copy` и обувница вне текущих категорий исключены.

В старом разделе обеденных групп представлены отдельные предметы, поэтому на новом сайте это подборка моделей для составления комплекта. Цена одного предмета не выдаётся за цену всей группы. Исторические цены и наличие не считаются подтверждёнными: это поясняется в каталоге и карточках.

Изображения скачаны локально и технически оптимизированы в WebP с сохранением пропорций. Повторный импорт выполняется вручную скриптом `scripts/import-catalog.py` по сохранённым исходным выгрузкам; эти внешние исходники и Python/Pillow не нужны для обычной сборки в CI.

## Границы версии

Форма валидирует данные и готовит сообщение для самостоятельной отправки в Telegram. Подтверждения доставки заявки менеджеру нет. Избранное хранит только номера моделей в localStorage этого браузера.

CMS, сервер приёма заявок, CRM, актуализация остатков, корзина и эквайринг требуют отдельного подключения. Сроки, гарантия, тарифы и итоговая комплектация согласуются с ателье; неподтверждённые условия со старых сайтов не перенесены.

Текущий логотип временный. Генерированная иллюстрация материалов явно подписана. Остальные фотографии предоставлены клиентом или перенесены из его прежнего каталога. Лицензии шрифтов и иконок: `public/assets/licenses/`.
