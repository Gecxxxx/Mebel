# Размещение сайта на VPS

Сервер: `89.124.104.61`. Проверочный HTTPS-адрес: `https://v763671.hosted-by-vdsina.com/`.
Сайт обслуживает nginx из `/var/www/prioritet/current`; ссылка указывает на неизменяемый выпуск в `releases/<source-commit>`.
MAX callback, видео и PDF на том же hostname продолжают работать. Заявки и подписки остаются в действующем приватном сервисе Sites/D1; его секреты и данные не переносятся в публичный каталог.

## Подготовка выпуска

1. Node.js 24, `npm ci`, `npm run build:pages` и проверки проекта.
2. `npm run build:vps` формирует корневую production-сборку с `SITE_URL=https://prioritetmebel48.ru` и `PUBLIC_INDEXABLE=true`.
3. Выполнить `npm run test:static` для production-сборки и `python deployment/vps/test_migration.py`.
4. Упаковать только содержимое `dist/client` в tar.gz. Вычислить SHA256 архива.
5. Скопировать файлы этой папки в `/opt/prioritet-site/operations`, архив — в `/tmp`.
6. На сервере выполнить `python3 /opt/prioritet-site/operations/install_site.py <archive> <sha256> <full-source-commit>`.

Установщик проверяет архив, свободное место и production-сборку. Он сохраняет закрытую резервную копию только собственных конфигураций, проверяет nginx и меняет ссылку текущего выпуска. При ошибке восстанавливает предыдущие настройки. Остальные приложения и системный Node.js не изменяются.

## DNS, переключается владельцем

| Тип | Имя | Значение |
| --- | --- | --- |
| A | @ | 89.124.104.61 |
| A | www | 89.124.104.61 |

Удалить конфликтующие старые A/CNAME и AAAA только для этих двух имён. При использовании Cloudflare выбрать **DNS only**, без проксирования. MX, TXT и записи других поддоменов сохранить. TTL 300 секунд подходит для переключения.

## HTTPS

До смены DNS основной домен продолжает обслуживаться прежним хостингом. На VPS заранее работает HTTP-vhost и ACME webroot `/var/lib/prioritet-site/acme`.

`prioritet-site-tls.timer` раз в минуту проверяет первоначальную готовность. Сертификат запрашивается только когда публичные A-записи указывают исключительно на VPS, нет старой AAAA-записи и проверочный HTTP-файл действительно приходит с VPS. Между неуспешными ACME-попытками выдерживается минимум 15 минут.

После смены DNS сертификаты apex и www выпускаются независимо. nginx включает HTTPS только с настоящим действующим сертификатом; www и HTTP затем перенаправляются на `https://prioritetmebel48.ru` с сохранением пути и query string. Во время первоначального выпуска после смены DNS возможен короткий перерыв HTTPS. Предварительная HTTPS-проверка выполняется по hostname провайдера, для которого сертификат уже действителен.

После установки обоих сертификатов bootstrap-таймер отключает себя. Далее работает уже существующий `certbot.timer`; сертификаты имеют свой deploy-hook проверки конфигурации и перезагрузки nginx.

Диагностика:

```sh
systemctl status nginx prioritet-max prioritet-site-tls.timer
journalctl -u prioritet-site-tls.service -n 30 --no-pager
cat /var/lib/prioritet-site/release.json
nginx -t
```

Push в GitHub по-прежнему обновляет прежние предпросмотры. Обновление VPS выполняется отдельным выпуском через этот установщик.

HTTPS-хосты сайта и шлюза используют HTTP/2 (синтаксис `listen ... ssl http2` для nginx 1.18). Статические HTML/CSS/JS сжимаются gzip, файлы `/_astro/` имеют immutable-кеш. Локальные шрифты отдаются в WOFF2; оригиналы TTF сохранены, повторное сжатие выполняет `scripts/compress-fonts.py`.

Production-сборка задаёт `PUBLIC_VPS_ORIGIN=https://prioritetmebel48.ru`: форма обращается к основному домену, видео и PDF берутся из локальных `/assets/marketing/`. Это исключает дополнительный DNS/TLS-запрос к hostname провайдера. Старые предпросмотры используют прежний шлюз; адрес callback MAX не меняется.
